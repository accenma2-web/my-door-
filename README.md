# My Door — دليل التشغيل بعد إضافة تسجيل الدخول وقاعدة البيانات

## اللي اتضاف

- **تسجيل دخول بطريقتين**، والعميل يختار وقت التسجيل:
  - إيميل + كلمة سر
  - رقم هاتف + رمز تحقق (OTP)
- **قاعدة بيانات Cloudflare D1** لحفظ المستخدمين والجلسات ورموز التحقق وبيانات التصاميم.
- **Cloudflare R2** لحفظ صور التصاميم المولّدة بالذكاء الاصطناعي.
- **سجل تصاميم شخصي**: كل مستخدم يشوف تصاميمه السابقة (زر 👤 أعلى الشاشة بعد تسجيل الدخول).
- **لوحة إدارة** لأي مستخدم بدور `admin`: تشوف كل المستخدمين وكل التصاميم.
- توليد التصميم وتحليل القصة بقى محتاج تسجيل دخول (مش متاح لزائر مش مسجل).

## 1) تجهيز Cloudflare

```bash
npm install -g wrangler
wrangler login

# قاعدة البيانات
wrangler d1 create my-door-db
# انسخ الـ database_id اللي هيظهر والصقه في wrangler.toml مكان REPLACE_WITH_YOUR_D1_DATABASE_ID

# تخزين الصور
wrangler r2 bucket create my-door-designs
```

## 2) تنفيذ الـ schema

```bash
wrangler d1 execute my-door-db --remote --file=schema.sql
```

## 3) الأسرار (Secrets)

```bash
# سر بتستخدمه مرة واحدة بس عشان تعمل أول حساب admin (اختار أي قيمة عشوائية طويلة)
wrangler secret put ADMIN_BOOTSTRAP_SECRET
```

## 4) النشر

```bash
wrangler deploy
```

## 5) عمل أول حساب Admin

1. افتح الموقع وسجّل حساب عادي (إيميل أو هاتف).
2. وأنت مسجّل دخول، ابعت الطلب ده (من التيرمنال أو من Postman):

```bash
curl -X POST https://YOUR-WORKER-URL/api/admin/bootstrap \
  -H "Content-Type: application/json" \
  --cookie "ddna_session=<انسخ قيمة الكوكي من متصفحك بعد الدخول>" \
  -d '{"secret":"القيمة اللي حطيتها في ADMIN_BOOTSTRAP_SECRET"}'
```

بعدها هيظهرلك زر "🛠️ لوحة الإدارة" في قايمة الحساب بالموقع.

## 6) تفعيل إرسال SMS حقيقي لرمز التحقق (OTP)

دلوقتي النظام شغال بـ **وضع تجربة (`OTP_DEBUG=1`)**: رمز التحقق بيرجع في نفس الاستجابة عشان تقدر تجرب الدخول بالهاتف من غير ما تدفع فلوس لمزود SMS. ده مكتوب في الواجهة كـ "وضع التجربة".

لما تكون جاهز لمزود SMS حقيقي (Twilio أو غيره):

1. افتح `worker.js` ودور على function اسمها `sendOtpSms` (فيها تعليق TODO واضح).
2. اكتب فيها كود الإرسال الفعلي لمزودك (فيه مثال جاهز في التعليقات).
3. سجّل مفتاح الـ API كسر:
   ```bash
   wrangler secret put SMS_PROVIDER_KEY
   ```
4. في `wrangler.toml`، فعّل السطر `SMS_PROVIDER_URL` وحط رابط API بتاع مزودك.
5. غيّر `OTP_DEBUG` لـ `"0"` في `wrangler.toml` بعد ما تتأكد إن الإرسال شغال.

## ملاحظات مهمة

- **حجم الصور في R2**: كل تصميم بيتحفظله لحد 6 صور. لو حبيت تقلل الاستهلاك، غيّر الرقم `6` في `handleSaveDesign` جوه `worker.js`.
- **جلسة الدخول**: الكوكي بتفضل شغالة 30 يوم، تقدر تغيّرها من `SESSION_MAX_AGE_SECONDS` في `worker.js`.
- **التصميم/منطق التوليد**: زي ما اتفقنا، هنرجعلهم بعد ما تختبر الجزء ده وتقولي التعديلات المطلوبة بالظبط.

## 7) دعم اللغات (عربي/إنجليزي)

التطبيق أصلاً بيدعم التبديل بين العربية والإنجليزية (زر 🌐 أعلى الشاشة، ومحفوظ في `localStorage`). تأكدنا من:

- شاشات تسجيل الدخول (إيميل/هاتف)، سجل التصاميم، ولوحة الإدارة بقت **بالكامل ثنائية اللغة** وبتتبدّل تلقائيًا مع نفس زر تبديل اللغة الموجود في التطبيق — مش نظام منفصل.
- لو حبيت تضيف لغة تالتة، دوّر على المتغير `DDNA_I18N` جوه `worker.js` (قريب من نهاية الملف) وضيف مفتاح لغة جديد بنفس شكل `ar`/`en`، وكمان لازم تضيف نفس اللغة في `LOCALE_MAP` بتاع التطبيق الأصلي.
- شاشات اختيار العقار والتصميم (DNA sliders والمفاهيم المقترحة) اتحدّث شكلها بلمسة ذهبية أفخم (حدود وشارات ذهبية، سلايدر بلون ذهبي) من غير ما يتلمس منطق الترجمة أو الحسابات بتاعتها.

## 8) إزاي تجرب التطبيق

### أ) تجربة محلية على جهازك (قبل النشر)

```bash
wrangler dev
```

هيديك رابط محلي (عادة `http://localhost:8787`). افتحه في المتصفح وجرّب كل حاجة (تسجيل دخول، توليد أبواب، سجل التصاميم). ملاحظة: بعض إعدادات D1/R2 محتاجة `--remote` أو محاكاة محلية — لو واجهت مشاكل بيانات محليًا:

```bash
wrangler dev --remote
```

### ب) تجربة بعد النشر الفعلي

```bash
wrangler deploy
```

هيديك رابط حقيقي زي `https://my-door.<your-subdomain>.workers.dev`. افتحه من موبايلك مباشرة في Chrome — التطبيق شغال زي أي موقع عادي، ومتاح فورًا لأي حد عنده الرابط.

## 9) خليته PWA (يتحمّل كأيقونة على الموبايل)

ضفتلك دعم **PWA** كامل (manifest + service worker + أيقونات) — يعني بعد النشر:

1. افتح رابط التطبيق من Chrome على أندرويد.
2. هيظهر اقتراح "إضافة إلى الشاشة الرئيسية" (Add to Home Screen) تلقائيًا، أو من قائمة المتصفح (⋮) اختار "Install app".
3. هيتحط أيقونة للتطبيق على الموبايل، وهيفتح من غير شريط عنوان المتصفح — حس استخدام قريب جدًا من تطبيق حقيقي، **من غير الحاجة لملف APK أصلاً**.

## 10) عايز ملف APK فعلي؟

**ملاحظة مهمة وصريحة:** إنتاج ملف APK حقيقي محتاج بيئة بناء أندرويد (Android SDK + Gradle) وتوقيع رقمي للملف — ده مش متاح في البيئة اللي بشتغل بيها دلوقتي (مفيش اتصال إنترنت لتحميل الأدوات، ومفيش Android SDK مثبت). يعني معنديش أقدر أبني الـAPK بنفسي هنا، لكن في طريقة سهلة وموثوقة تعملها بنفسك في دقايق من غير ما تحتاج Android Studio:

### الطريقة الأسهل: PWABuilder (مجاني، من المتصفح فقط)

1. انشر التطبيق الأول (`wrangler deploy`) وخد الرابط الحقيقي بتاعه.
2. افتح **https://www.pwabuilder.com**
3. الصق رابط تطبيقك واضغط Start.
4. هيقرأ الـmanifest اللي ضفناه تلقائيًا ويديك تقييم (Report Card).
5. اضغط على خيار **Android** → هيديك خيارين:
   - **TWA (Trusted Web Activity)** — الموصى بيه، بيفتح موقعك جوه غلاف أندرويد حقيقي بدون شريط متصفح.
   - هيولّدلك ملف APK أو Android Studio project جاهز تعمله build.
6. تقدر تنزل الـ APK مباشرة (لو اخترت التوقيع التجريبي بتاعهم) أو تنزل الكود وتعمله build وتوقيع بنفسك لو عايز تنشره على Google Play.

### بديل: Android Studio + Bubblewrap (لو عايز تحكم أكتر)

```bash
npm install -g @bubblewrap/cli
bubblewrap init --manifest=https://YOUR-WORKER-URL/manifest.json
bubblewrap build
```

ده محتاج Java JDK وAndroid SDK متثبتين على جهازك (Bubblewrap بيتأكد ويرشدك لو ناقص حاجة).

**خلاصة:** التطبيق دلوقتي شغال زي PWA كامل — التثبيت على الموبايل بقى ممكن من غير APK أصلاً، ولو محتاج ملف APK فعلي (مثلاً عشان ترفعه على Google Play)، PWABuilder هو أسرع طريق وهياخد منك دقايق مش أكتر.
